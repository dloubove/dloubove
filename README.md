# Hey there! 👋

I'm **Dan LOUBOVE** — a Computer Science Engineering student based in **Douala, Cameroon** 🇨🇲

I build whatever comes to mind — if I can imagine it, I'll code it, ship it, and learn from it.

My main focus is **building digital products that solve real problems for Central Africa** — from e-commerce to digital health to real estate platforms.

I'm also deeply into **networks, algorithms, and DIY electronics** — the kind of builder who reads datasheets for fun.

I've got a handful of public projects, but my favorite is **[BGR Society](https://github.com/dloubove/bgr-society-social-network-for-sharing-documents-between-students)** — a student document-sharing social network I'm building for university communities.
